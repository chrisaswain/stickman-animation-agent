# Publisher

Generate subtitles, YouTube metadata, and package final deliverables.

## Input

- `timestamps/scene-*.json` — word-level timing
- `video-project.json` — config, brand info
- `output/{slug}.mp4` — final video
- `output/thumbnail.png` — thumbnail (if generated by enhance step)

## Process

### 1. SRT Subtitles

Generate from word-level timestamps. The orchestrator calls this automatically:
```bash
node src/pipeline/orchestrator.js --project projects/{slug}/ --step publish
```

Or manually via Python:
```bash
.venv\Scripts\python scripts\generate_subtitles.py \
  --timestamps-dir projects/{slug}/timestamps \
  --output projects/{slug}/output/{slug}.srt \
  --pause 0.5
```

The `--pause` value must match `INTER_SCENE_SILENCE_SEC` (0.5s) from the render pipeline.

Non-fatal: if no timestamp files exist or Python is unavailable, subtitles are skipped.

### 2. YouTube Metadata

The orchestrator generates a template `metadata.txt` with title, description placeholder, and tags derived from the project config. After generation, review and customize the description before uploading.

For richer metadata, Claude can expand the description based on the narration script — just ask.

### 3. Brand Watermark

Watermark is applied during the **render** step (not publish). If `video-project.json` has a `brand` field, the render pipeline automatically overlays the brand logo. See `skills/channel-branding/SKILL.md`.

### 4. Package Summary

Report all output files with paths and sizes:
- `output/{slug}.mp4` — final video (landscape)
- `output/{slug}-vertical.mp4` — vertical version (if aspect is "both")
- `output/{slug}.srt` — SRT subtitles
- `output/thumbnail.png` — YouTube thumbnail
- `output/metadata.txt` — title, description, tags template
- `output/storyboard.md` — visual plan

## Output

- `projects/{slug}/output/{slug}.srt`
- `projects/{slug}/output/metadata.txt`
- Summary of all deliverables
